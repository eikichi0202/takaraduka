Eikichi Racing Simulator v8.58.46 — 代替能力8段階・比較検証版

■ 使い方
ZIPを展開し、index.html と8本の .js を同じフォルダーに置いて開きます。
GitHub Pagesで使う場合も9ファイルを同じ階層に置きます。
出馬表に「血統登録番号」（または血統登録No）を含めてください。年齢限定・年齢条件があれば優先します。
試算の対象は戦歴のある平地戦です。新馬・障害は試算対象外です。

■ 表示と一括CSV
検証結果の「代替能力(試算)」にはSS／S／AA／A／B／C＋／C／Dと表示能力点が出ます。
マウスを合わせると、同じ芝・ダートの直近補9、近距離上位、同級・同距離・同年齢区分の補正、参照数が見られます。
単レース・一括の両CSVには、試算点、根拠、H7余力、ランク、確度、圧縮前の点、戦歴最終日、モデル版を保存します。
C＋の圧縮前の点はB76とC71の中間の73.5です。欠損時のC＋には「暫定」が付きます。
SS91、S86、AA83、A81、B76、C＋73.5、C71、D66はv8.58.45の尺度に合わせています。
画面の点は圧縮率・馬場反映率を反映。試算ランク自体は出走相手の顔ぶれに依存しません。

■ 参照する戦歴
代替試算専用の戦歴は2021年から2026年11月15日まで。対象日より前の出走のみを使います。
同じ芝・ダートで近7出走を確認し、直近と、距離・競馬場が近い実績の水準を評価します。
年齢区分とクラスを条件に含め、若齢戦の補9に一律の二重減点は掛けません。
直近3走や近い条件の実績に含まれない近7走の最高補9は、180日以内で別走に近い値の裏付けがある場合だけ小幅加点します。
余力は圧縮前で最大0.8点です。この余力の単独加点でランクを上げません。
TARGETの入力H7は出馬表相対値の場合があるため、数値が異なる場合は補9との差を加点に使いません。
現行予測・買いランクの処理はv8.58.45の計算を使用します。

■ 比較する開催
2026年11月21・22・23日の一括CSVを比較用に保存してください。3日とも代替試算の戦歴は11月15日までの共通時点です。
現行・代替のランク差、順位、実着順を同じ馬・同じレースで比較できます。
