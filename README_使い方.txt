Eikichi Racing Simulator v8.58.44 登録番号照合版

index.html と同梱の7つの .js を同じフォルダーに置いてください。GitHubへも8ファイルを同じ階層にアップロードします。前版の3つの horse_history_part*.js と index.html を入れ替えてください。

2021～2026年の再出力は全278,942件で血統登録番号があり、補9は旧出力と全件一致しました。旧出力と差のあった「補正」231,898件は今回の値を採用した別のSQLite履歴DBを作成しました。今回の「補正」は全件で「補9」と同じ値です。この一致の理由は出力ファイルだけでは特定できません。補9の計算にはこれまでどおりTARGETの「補9」を使用します。

出馬表に血統登録番号があれば番号で過去走を照合します。番号がないときだけ従来の馬名・父・母父を使用します。代替能力は引き続き参考表示で、予測に使うのは入力された現行能力です。番号照合で従来見つからなかった補9が見つかる馬は、既存の補9能力補助を通じて予測が変わる場合があります。履歴収録は2026年11月8日までです。
