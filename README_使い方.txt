Eikichi Racing Simulator v8.58.38 クラス水準表示版

このフォルダーの index.html と7つの .js ファイルを同じ場所に置いてください。GitHubでも8ファイルを同じ階層に配置します。

買いランクCの「紐候補」に、クラス水準を満たす場合だけ「H7水準以上」「補9水準以上」を表示します。レース内上位半分という判定は廃止しました。詳細で各値・採用した基準を確認できます。0と欠損は水準達成にしません。

過去走加重補9の表示基準：未勝利77、1勝88、2勝95、3勝100、オープン／リステッド105。
H7の表示基準：未勝利80、1勝90、2勝100、3勝105、オープン／リステッド110。H7の長期履歴はなく、直近データに基づく暫定的な目安です。
重賞は添付された年齢区分×G1/G2/G3表の下限を両指数の表示目安に使用します。H7への重賞表適用は暫定です。レース名と開催月から年齢区分を自動判定し、「重賞の年齢区分」で修正できます。

補9はTARGETの単走値でなく、同芝ダートの過去走を条件で重み付けした参考値です。表示基準の達成は馬券内確率を意味しません。
H7・補9の既存の小幅な能力補助はそのままです。今回の表示変更で能力点、実効指数、勝率、連対率、複勝率、買いランク、レース信頼度の計算を追加変更しません。
