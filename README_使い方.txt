Eikichi Racing Simulator v8.58.45 代替能力3指数検証版

index.html と同梱の7つの .js を同じフォルダーに置いてください。GitHubにも8ファイルを同じ階層へアップロードします。v8.58.44から更新したのは index.html と horse_history_part1.js～part3.js です。

「代替能力(試算)」は、前回のクラス相対「補正」と今回の「補9」を各々同芝ダート・予測日前の近10走から条件加重し、レース内順位百分位の平均を能力の基礎とします。H7はその基礎より百分位が高いときのみ差の25%を上乗せする余力の参考値です。H7が低くても減点しません。指数欠損は低能力とはみなさず、1種類しか基礎がない場合はその値を使用、両方ない場合はH7のみを低信頼として使用、全てなければ中立。新馬は対象外です。

現行能力を使う5000回シミュレーション、勝率・連対率・複勝率、買いランク、レース信頼度はv8.58.44と同じです。補9・H7の既存の小幅な能力補助もそのままです。代替能力は画面とCSVの参考表示だけです。登録番号による過去走照合も維持します。

単レース・一括CSVには代替能力の値・根拠・H7余力加点に加え、旧補正の過去走加重値と参照数を出力します。履歴収録は2026年11月8日まで。6開催日の予備検証では改善傾向がありましたが、能力値を本番採用できる精度かは未確定です。
