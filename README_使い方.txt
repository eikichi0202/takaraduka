Eikichi Racing Simulator v8.58.41 確定馬場一括検証版

index.html と7つの .js を同じ場所に置いてください。GitHubへは8ファイルを同じ階層へアップロードします。

全レース一括検証では各レースの確定結果から馬場を先に取得し、そのレースの5000回シミュレーションへ適用します。レースごとの確定馬場は保存し、途中で馬場が変化しても各レースの実際の馬場で検証します。確定馬場を確認できないレースはスキップします。

v8.58.39の厩舎コンディション試行反映、新馬の道悪ウェイト、H7・過去走加重補9のクラス水準表示を維持します。S/A軸がないレースは買い見送りと表示し、B以下の最上位馬は参考情報として表示します。予測精度の改善幅は未検証です。
