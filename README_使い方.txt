Eikichi Racing Simulator v8.58.36 検証版

このフォルダーの index.html と7つの .js ファイルを同じ場所に置いてください。
GitHubへ置く場合も8ファイルを同じ階層にアップロードします。各ファイルは25MB未満です。

出走表に H7 列があれば読み込み時に数値を保持します。空欄と0は加点しません。
新馬戦はH7を加点しません。未勝利戦は条件を満たすと小幅に加点します。
補正9は過去走DBの対象馬のみ小幅加点します。2指数の追加点は最大1.15点です。
ラップ血統は予想された瞬発・持続・消耗の割合を使い、血統点へ最大±0.7点です。
新潟・福島のペース予測は暫定的にハイ側へ最大4ポイント移します。

各馬の買いランクの詳細を開くと、H7・補正9・ラップ血統の加点を確認できます。
検証結果の「能力」の右に「補9」を表示します。これは過去走の補正9を条件で重み付けした参考値で、履歴がない場合は「－」です。
単走のレースアニメーションにも固定二次補正の上限を適用しました。勝率・連対率・複勝率を出す5000回検証は、以前から上限が適用されており計算は変更していません。
出力CSVにも H7入力値、H7能力加点、過去走補9能力反映pt、能力追加合計、
予想瞬発%、予想持続%、予想消耗%、ラップ血統加点 を記録します。

この版の勝率・複勝率の改善幅はまだ未検証です。
予測計算は v8.58.34 から変更していません。元の v8.58.34・v8.58.35 とデータ資産は変更していません。
